# MuzTalk branding assets

Integrated assets:
- `mobile/assets/muztalk-icon.png`: Expo launcher icon (1024x1024)
- `mobile/assets/muztalk-adaptive-foreground.png`: Android adaptive icon foreground
- `mobile/assets/muztalk-splash.png`: Expo splash screen (1242x2436)
- `android/app/src/main/res/mipmap-*`: native Android launcher icons
- `android/app/src/main/res/drawable/muztalk_launch_background.xml`: native launch background
- `public/favicon.png`: web favicon

The Android native splash uses a navy background and the MuzTalk mark. Expo builds use the branded full splash artwork. Rebuild the Android APK/AAB after changing these resources.
